Plan a group camping trip without the gear-and-grocery guessing game

Short answer

Vacationist coordinates who's bringing the tent and the stove with a shared packing list, splits campsite fees and groceries the moment they happen, and keeps working offline-first when the campground has no signal.

The problem with planning a group camping trip

Group camping runs on shared gear and a shared kitchen, and both are easy to get wrong without a plan everyone can see. Someone assumes someone else is bringing the stove; nobody is. The grocery run for a shared camp dinner gets paid by whoever happened to be at the store, and reimbursement turns into an afterthought nobody follows up on. Meal planning for a group is its own puzzle — figuring out who's cooking what night and what ingredients that actually requires. And campgrounds are usually exactly where phone signal disappears, so whatever app the group is using needs to work without it.

How Vacationist handles it

A shared packing list that keeps gear from getting duplicated or forgotten

One real-time list for tents, stoves, coolers, and food — so the group doesn't end up with three lanterns and no bottle opener. Recipes for shared camp meals can sync straight into the shopping list, so the grocery run matches what's actually being cooked. Explore shared lists.

Split campsite fees and groceries as they happen

Log the campsite booking, firewood, and each grocery run as its own cost, split equally or with custom amounts. Balances update live, so whoever fronts the big grocery trip isn't quietly out of pocket until the trip ends. See how expense splitting works.

Vote on which campground or weekend works

Suggest a campground or date, and let the group vote with a five-tier system from "must do" to "group blocker" — useful when half the group wants a lake site and the other half wants mountains.

Works offline-first, right where signal usually disappears

Votes, expenses, and list updates are saved locally with no connection and sync automatically once someone's phone finds signal — which matters at almost every campground.

What it costs

Free, with no ads. Voting, expense splitting, shared lists, and guest access are free for the whole group. A Pro tier exists for organizers running frequent trips, but it isn't required for a single camping weekend.

Frequently asked questions

Does the recipe-to-shopping-list sync actually work for camp meals?

Yes — add a recipe for a planned camp dinner and its ingredients sync into the shared shopping list, so the grocery run matches what the group is actually cooking.

Does it work at a campsite with no signal?

Yes. Vacationist is offline-first — votes, expenses, and list changes save locally without a connection and sync automatically once a phone reconnects.

Can we split the cost of shared gear rental, like a canoe or extra tents?

Yes — log it as its own expense and split it with custom amounts, separate from campsite fees and groceries.

Can we track a multi-stop trip with more than one campsite?

Yes — the shared calendar tracks each stop, so a multi-night trip across different campgrounds stays on one timeline instead of separate plans per stop.
